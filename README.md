🛍️ Lenskart Store Performance Dashboard (Power BI)
📌 Project Overview

This project is a Power BI dashboard designed to simulate real-world retail analytics for a store manager role. It focuses on key business KPIs such as sales performance, customer conversion, and product insights.

The dataset is structured using a two-layer model:

Daily Summary Table → for KPIs like footfall and total sales

Transaction Table → for detailed order-level analysis

🎯 Objective

To enable data-driven decision-making for a retail store by analyzing:

Sales trends

Customer behavior (new vs repeat)

Store-wise performance

Product category performance

📊 Key KPIs

Total Sales

Total Orders

Footfall

Conversion Rate

Average Bill Value (ABV)

📈 Dashboard Features

Interactive slicers (Store & Month)

Sales trend analysis (time-based)

Category-wise performance

Top-selling products

Customer segmentation (First-time vs Repeat)

Weekend vs Weekday analysis

🧠 Data Modeling

Created a composite key (Date + Store) to establish relationships between tables

Used one-to-many relationship for proper filter propagation

Implemented calculated columns and measures (DAX) for KPIs

⚙️ Tools & Technologies

Power BI

DAX (Data Analysis Expressions)

Excel (Data Simulation & Preparation)

📁 Files Included

Power BI Dashboard (.pbix)

Excel Dataset (.xlsx)

DAX Measures Documentation

🚀 Key Insights

Identified high-performing product categories

Analyzed conversion efficiency across stores

Evaluated customer retention through repeat purchases

Compared weekday vs weekend performance

This project demonstrates:

Real-world data modeling techniques
